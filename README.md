# GlobalPulse News | The Prank Website 📰⚡

A modern, responsive news aggregator that hides a chaotic secret. To the unsuspecting user, it looks like a premium technology news site. Once they click anywhere, the "GlobalPulse" experience transforms into an immersive, high-volume prank.

## 🚀 Features

- **Dynamic News Fetching**: Pulls real-time tech headlines using search APIs.
- **Premium UI**: Built with React and Tailwind CSS, featuring a clean, professional news layout with hero sections, sidebars, and breaking news banners.
- **The Prank Mode**:
  - **Instant Trigger**: Any click on the page activates the sequence.
  - **Visual Chaos**: Swaps to a high-contrast, flickering "Comic Sans" theme with inverted and rotating images.
  - **Audio Immersion**: Plays a high-volume, "ear-rape" version of the classic PPAP (Pen Pineapple Apple Pen) meme.
  - **Fullscreen Lock**: Automatically attempts to enter fullscreen mode for maximum impact.
  - **Randomization**: News articles are randomized on every refresh to keep the bait fresh.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **API Handling**: Fetch API / Axios

## 🏃 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/prank-website.git
   cd prank-website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   *By default, the app runs on `http://localhost:5173`. You can change the port using `npx vite --port XXXX`.*

## 📂 Project Structure

- `/src/App.jsx`: Main application logic and prank controller.
- `/src/index.css`: Global styles and the "Prank Mode" CSS animations.
- `/src/assets/`: Contains the prank audio payload.
- `/public/`: Fast-loading assets like the newspaper favicon.
